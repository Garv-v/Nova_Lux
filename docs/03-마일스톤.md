# 마일스톤 (미확정)

규칙과 수치는 [기획서](02-기획서.md), 용어는 [CONTEXT.md](../CONTEXT.md)에 있다. 이 문서는 제작 순서이며 전체가 제안 단계다.

## M1. 초기화면 + 환경설정

- 초기화면: 새로 시작 / 이어하기 / 갤러리 / 환경설정 / 종료 (기획서 13장).
- 환경설정: 음량 3종, 텍스트 속도, 자동 진행 속도, 전체화면/창모드, 해상도 720p~4K, 언어(한국어·일본어).
- 아트는 임시 박스로 만든다. 갤러리는 잠긴 이미지 자리만 둔다.

완료 기준:
- 해상도 720p, 1080p, 4K에서 UI가 깨지지 않는다.
- 설정을 바꾸고 재실행해도 값이 유지된다.
- 언어를 바꾸면 모든 문자열이 바뀐다.
- 갤러리를 눌러도 에러 없이 잠긴 이미지가 보인다.

구현 때 정할 것:
- 언어 전환 방식 (Unity Localization 패키지 또는 자체 문자열 표). 확인 안 함.
- 설정 저장 방식.
- 한글+일본어 폰트 글리프 처리. 시작 전에 확인한다.

## M2. 복도 프로토타입

- 금태양 좌우 걷기 (스프라이트 한 세트, 임시 도형), 가로로 긴 복도 배경 한 장, 카메라 경계.
- 문 앞에서 입장하면 페이드로 방 임시 화면(박스)으로 넘어가고, 나가면 복도로 돌아온다.
- 이동은 행동력을 쓰지 않는다. 방 안 상호작용 자리만 표시한다.

완료 기준:
- 좌우 걷기가 된다.
- 문 입장과 퇴장이 왕복된다.
- 720p, 1080p, 4K에서 복도 비율이 유지된다 (16:9 고정, 레터박스).

판정 지점: 걷기가 조작이나 제작에서 부담이 되는지 본다. 괜찮으면 [ADR-0005](adr/0005-복도횡스크롤-방아이소.md)를 `accepted`로 바꾸고, 아니면 아이소 화면 탭 이동으로 바꾼다.

## M3 이후 (후보)

- 방 하나로 아이소메트릭 포즈 장면을 시험한다 (여주 방과 공실 엿보기가 후보).
- 하루 진행과 행동력을 돌리는 최소 루프를 만든다.

## 참고

M1과 M2는 파일이 겹치지 않아 2인 팀이 나눠 동시에 해도 된다. 기본 순서는 M1 다음 M2다.
