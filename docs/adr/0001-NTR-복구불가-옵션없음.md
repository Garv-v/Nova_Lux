# NTR은 복구할 수 없고 끄는 옵션도 없다

이 게임의 핵심 재미는 "내 것을 빼앗긴다"는 체감이다. 연인이 된 여주가 NTR로 확정되면 복구할 수 없고, NTR을 끄는 옵션도 두지 않는다.

## Considered Options

- 역전 또는 이벤트로 복구 가능: 한 번의 실수가 치명적이지 않아 불호 리뷰가 줄지만, 빼앗겼다는 무게가 약해진다.
- NTR 표시 ON/OFF 옵션: 구매층은 넓어지지만 OFF 분기용 연출과 문서가 늘고 컨셉이 흐려진다.

## Consequences

- 복구가 없으므로 징후 이벤트(단서)와 크기 5단계의 안전 장치가 공정성을 책임진다 ([ADR-0002](0002-타락도-비공개-열람아이템.md), [ADR-0003](0003-크기5단계-타락도정지.md)).
- 작품 소개에 NTR 요소를 분명히 밝혀 구매 전 기대치를 맞춰야 한다.

## 개정 (2026-10-23)

"복구 불가"는 게임 안에 되돌릴 수단이 없다는 뜻이다. 수동 다중 슬롯 세이브([ADR-0007](0007-세이브-다중슬롯과-영구해금.md))로 플레이어가 이전 저장을 불러오는 것은 막지 않는다. 세이브를 쓸지는 플레이어의 몫이고, 공정성은 징후와 안전 장치가 계속 책임진다.
