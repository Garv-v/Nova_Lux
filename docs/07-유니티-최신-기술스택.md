# 유니티 최신 기술스택 조사

조사일 2026-10-29. 1차 출처만 썼다(Unity 공식 문서·릴리스 노트·Unity Discussions 공식 글·패키지 CHANGELOG·공식 GitHub). 검색 결과 스니펫만 본 항목은 "(스니펫)"으로 표시했다. 확인 못 한 것은 "확인 안 함"이다. 코드는 바꾸지 않았다.

## (a) 한 줄 요약

6000.6.2f1은 **Supported(비LTS) 라인의 최신이 아니다**(6000.6.6f1이 최신). 6.6이 Unity 6의 마지막 Supported 릴리스이고 다음 LTS는 6.7(문서상 지금 Beta)이며 Unity 7 프리뷰는 12월, 정식은 2027 Q1 목표다. Nova_Lux 패키지는 거의 최신이고, 지금 조치할 것은 (1) 6000.6.6f1 패치, (2) 이미 꺼 둔 도메인 리로드 때문에 생기는 static 상태 점검, (3) Unity CLI/pipeline 패키지가 베타라는 점 인지다.

## (d) 권고

**쓸 수 있는 것**
- **6000.6.6f1로 패치 업**: 6.6.2의 알려진 문제(Bloom + 2D Renderer 검은 화면)와 6.6.6의 2D Renderer 수정(오버레이 카메라 ArgumentException, Render Objects)이 이 프로젝트 스택(2D URP, 오버레이 UI 카메라 가능성)과 겹친다. 같은 라인이라 파괴적 변경은 없다. 단 적용하면 `Assets/Settings/UniversalRP*.asset` 등 이미 수정 중인 파일과 섞이지 않게 별도 브랜치에서 한다.
- **Input System 1.20.1**: 에디터 UI 수정뿐이다. 필수는 아니다.
- **Code Coverage 1.3**: 테스트가 이미 많아(PlayMode) 비용이 작다. 필요해질 때 설치.
- **UI Toolkit/ATG, Panel Renderer**는 새 UI를 만들 때 검토 대상이다(6.5 이후). 지금은 쓰지 않는 쪽이 낫다(아래).

**쓰면 이득인 것**
- **Project Auditor static 분석(UAL)으로 static 상태 점검**: 이미 도메인 리로드를 꺼 둔 프로젝트이고 Unity 7은 리로드를 없앤다. 지금 정리해 두면 7 이행 비용이 준다.
- **6.7 LTS를 대비한 일정 결정**: 6.6 지원은 6.7 출시 때 끝난다. 6.7 LTS 출시일은 확인 못 했으니, 출시 공지가 나오면 그때 업그레이드 여부를 결정한다. 6.7은 Mono 마지막 LTS라 Unity 7 직전 안전한 선택지다.
- **`Graphics.RenderSprite`/`RenderSpriteInstanced`**: 미리 알아 둘 정도다. 복도 걷기·방 한 장 구조(ADR-0005)에는 필요 없다.
- **Localization 패키지는 ADR-0006의 재검토 조건(대사 수백 건·복수형·에셋 로컬라이즈)이 올 때** 다시 본다. 패키지는 Smart Strings와 CSV/XLIFF 가져오기·내보내기를 제공한다. 대사 양이 늘면 번역 작업 흐름(CSV)이 이득이지만, 자체 `Loc` 인터페이스를 유지하는 방법(ADR Consequences)도 있다. 지금 도입은 비권장.
- **Unity CLI + 현재 쓰는 MCP**: 이미 `unity` 명령이 CLAUDE.md 1순위다. 베타라 옵션·종료 코드 같은 파괴적 변경이 또 나올 수 있으니(beta.14 사례) 버전 고정과 `unity --version` 기록을 권한다.

**쓰지 말 것**
- **CoreCLR 데스크톱 플레이어(6.7 실험)**: 운영 프로젝트 사용 금지 경고가 공식 글에 있다.
- **6000.7 Beta / Unity 7 Alpha·프리뷰**: 개발 중인 게임에 부적합. 프리뷰는 12월 예정.
- **UI Toolkit 월드 스페이스를 2D 소팅 레이어와 섞는 구성**: 소팅 레이어 통합 미지원(공식 문서).
- **UI를 uGUI(TMP)에서 UI Toolkit으로 옮기기**: 한·일 동적 아틀라스 폰트 동작을 공식 문서로 확인하지 못했고, 이 프로젝트의 `LocText`·`UiKit`·테스트가 uGUI 전제다(코드 구조 판단, 확인 안 함). 이점이 불분명하다.
- **Entities/Burst, Physics Core 2D, 동적 배칭**: 이 게임 규모와 무관하거나 obsolete다.
- **`com.unity.serialization` 신규 도입**: 6.6에서 deprecated.
- **실험 패키지(`com.unity.pipeline` exp)를 새 기능 기반으로 삼기**: 실험은 지원 보장이 없다. CLI가 의존하므로 버전은 CLI 안내를 따른다.

기타: `com.unity.learn.iet-framework`는 환영 창용 패키지로 보이나(6000.6.x 환영 창을 끈 커밋 `6c388c1`이 있음) 용도는 확인 안 함. 제거 후보지만 코드 변경이라 이 조사 범위에서 제외.

- 6.7 LTS 정확한 출시일: 공식 글에 날짜 없음(June 2026 CoreCLR 글은 날짜 미언급).
